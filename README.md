# Character Counter

Aplicación desarrollada con React y Vite para analizar texto en tiempo real.

## Funcionalidades

- Conteo de caracteres
- Conteo de palabras
- Conteo de oraciones
- Tiempo estimado de lectura
- Opción para excluir espacios
- Límite de caracteres
- Densidad de letras
- Modo claro y oscuro
- Diseño responsive

## Tecnologías utilizadas

- React
- JavaScript
- CSS
- Vite

## Ejecutar el proyecto

```bash
npm install
npm run dev
